# 🚀 GoSense v0.2.3 - Console Publisher Added

## 📺 **Console Publisher Release**

This release adds the missing console publisher to the public API, completing the publisher ecosystem.

## ✨ **What's New**

### **🖥️ Console Publisher**
- **NEW**: `gosense.NewConsolePublisher[T]()` for development and testing
- **NEW**: Console output with formatted sensor data display
- **NEW**: Batch and individual message support with visual indicators
- **ENHANCED**: Complete publisher ecosystem now available

### **📋 Complete Publisher Support**
GoSense now provides **4 complete publishers**:

1. **`GenericHTTPPublisher[T]`** - HTTP/REST API publishing
2. **`GenericKafkaPublisher[T]`** - Apache Kafka streaming  
3. **`GenericGRPCPublisher[T]`** - gRPC low-latency communication
4. **`ConsolePublisher[T]`** - Console output for development ✨ **NEW**

## 📖 **Usage Examples**

### **Console Publisher for Development**
```go
import "github.com/Utsav-pixel/gosense"

// Perfect for development and testing
publisher := gosense.NewConsolePublisher[YourData]()

// Shows formatted output:
// 📦 Batch of 2 items:
//   [0] [OK] {Value:42.5 Location:"sensor-1"}
//   [1] [PARTIAL] {Value:38.2 Location:"sensor-2"}
```

### **All Publishers Available**
```go
// Development
consolePublisher := gosense.NewConsolePublisher[YourData]()

// Production
httpPublisher := gosense.NewGenericHTTPPublisher[YourData]("https://api.example.com/data")
kafkaPublisher := gosense.NewGenericKafkaPublisher[YourData]([]string{"localhost:9092"}, "topic")
grpcPublisher, err := gosense.NewGenericGRPCPublisher[YourData]("localhost:50051")
```

## 🎯 **Why Console Publisher?**

### **Development Benefits**
- ✅ **Quick Testing** - No external services required
- ✅ **Visual Feedback** - Formatted output with quality indicators
- ✅ **Debugging** - See exactly what data is being generated
- ✅ **Prototyping** - Test sensor logic without infrastructure

### **Output Format**
```
📦 Batch of 2 items:
  [0] [OK] {Value:67.37 Location:"test-sensor"}
  [1] [PARTIAL] {Value:80.40 Location:"test-sensor"}
🔚 Console publisher closed
```
